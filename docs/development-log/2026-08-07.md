### Design

Full rationale in
[ADR-017](../decisions/ADR-017-organization-identity-and-ownership.md).
The genuinely hard decisions: keeping `ORGANIZATION` role and
`VERIFIED` organization status as two independently-checked facts
everywhere, never conflated; making `resources.organization_id` (not a
claim's `status`) the sole ownership authority; a verification-reset
policy that resets on identity-significant edits (name, website) but
not on contact-only edits; restricting organization/claim admin
routes to `ADMIN` only, not `ADMIN`/`MODERATOR` like moderation; and
— the hardest one — claim-approval concurrency, which needed a second
lock (the target resource row, reusing
`ResourceRepository.findByIdForUpdate`) beyond the claim row's own
lock, since two *different* organizations' claims are two different
rows that a claim-row-only lock would never serialize against each
other.

`com.hfxconnect.organization` package (entities/repositories for
`Organization`/`ResourceOwnershipClaim`/`OrganizationAuditEvent`,
`OrganizationService`/`AdminOrganizationService`/
`ResourceOwnershipClaimService`/`AdminResourceOwnershipClaimService`/
`OrganizationResourceService`, five controllers, DTOs, seven exception
types); promoted `SelfReviewNotAllowedException`/

not a `@ManyToOne`, to avoid circular package coupling — see ADR-017)
and batch organization-summary loading threaded through search, nearby
search, and single-resource detail; `SecurityConfig` wiring for
`/api/v1/organizations/me/**` (`ORGANIZATION`), the public slug route,
and `/api/v1/admin/organizations/**`/`/api/v1/admin/resource-
ownership-claims/**` (`ADMIN` only). Frontend: `lib/api/organization.ts`,
`lib/query/use-organization.ts`, four new key factories, a new
`patchJson` client function (this codebase's first `PATCH`), fourteen
new `components/organization/` files including two new route guards
(`OrganizationRoute`, `AdminRoute` — the latter the first `ADMIN`-only
frontend guard), eight new routes across `/organization/**` and the
first `/admin/**` frontend section, nav integration, `AuthProvider`
cache-clearing extended to three more private prefixes (deliberately
excluding the new public-organization prefix), and a claim control
