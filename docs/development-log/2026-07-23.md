## Known Limitations

- No resource update/delete HTTP endpoints (deliberately out of scope; the
  business-layer methods exist and are tested).
- No `verificationStatus` or `active` filter on the public list endpoint (see
  milestone document).
- No authentication; `POST /api/v1/resources` is unsecured, identical to the
  Category API's existing limitation.
- Schema does not yet include `accessibilityInformation`, `lastVerifiedAt`, or the
  expanded cost/verification enum values some planning documents describe — deferred
  to whichever future milestone actually needs them (see milestone document).
