## Problems Encountered

The generated Spring Boot parent POM version (`4.1.0.RELEASE`) failed to resolve from
Maven Central. The `spring-boot-starter-parent` artifact is not actually published
under a `.RELEASE`-suffixed version for Spring Boot 4.x — that suffix is part of
Spring Initializr's metadata `id` field, not the real Maven coordinate.

## Resolution

Queried Maven Central's `maven-metadata.xml` for `spring-boot-starter-parent`
directly, found the real published version (`4.1.0`), and corrected `pom.xml`. The
build then resolved and succeeded.
